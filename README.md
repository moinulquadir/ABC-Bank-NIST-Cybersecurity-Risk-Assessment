# ABC Bank – NIST Cybersecurity Risk Assessment

A hypothetical cybersecurity risk assessment portfolio project for a small U.S. financial institution, using the NIST Cybersecurity Framework (CSF) 2.0.

## Project purpose
This project demonstrates a practical risk-management lifecycle:
**Identify → Analyze → Assess → Assign Owner → Select Treatment → Implement Control → Test → Determine Residual Risk → Management Review → Monitor → Remediate/Reassess**

## Included artifacts
- Asset inventory with 20 realistic banking assets
- 30-item cybersecurity risk register
- NIST CSF 2.0 category mapping
- Control tests with evidence, results and findings
- Remediation findings with owners, priorities and due dates

## Key risk themes
- Identity and privileged-access weaknesses
- Endpoint patching and EDR coverage
- Backup immutability and recovery testing
- SIEM logging and detection coverage
- Firewall and network segmentation
- Third-party access and supply-chain risk
- Vulnerability-management coverage
- Disaster-recovery readiness

## Disclaimer
ABC Bank is fictional. No real customer, employee, financial or confidential information is used. This repository is a cybersecurity portfolio project and does not represent work performed for a real bank.
