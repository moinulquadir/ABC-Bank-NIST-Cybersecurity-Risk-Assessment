# ISO/IEC 27001:2022 Implementation Project — Northstar Software Labs

> **Portfolio project:** End-to-end Information Security Management System (ISMS) implementation for a fictional B2B SaaS software company.

## Executive summary
Northstar Software Labs is a fictional 180-person SaaS company that develops and operates a cloud-hosted workflow platform used by business customers. The company decided to implement an ISMS aligned to **ISO/IEC 27001:2022** to improve governance, manage information-security risk consistently, strengthen customer trust, and prepare for an external certification audit.

This project demonstrates how an information-security implementation can be managed as a real project from **initiation through closure**, including governance, scope, asset inventory, risk assessment, risk treatment, Statement of Applicability (SoA), control implementation, evidence collection, internal audit, corrective actions, management review, and certification readiness.

## Project scenario
- Company: Northstar Software Labs
- Industry: B2B SaaS / software development
- Employees: 180
- Locations: New York HQ + remote workforce
- Cloud: AWS
- Primary product: Northstar Workflow SaaS
- Key information: customer business data, source code, credentials/secrets, employee data, contracts, security logs
- Target: ISO/IEC 27001:2022 readiness and certification preparation
- Project sponsor: Chief Operating Officer
- ISMS owner: Head of Information Security
- Project manager: Information Security Program Manager
- Assessment approach: risk-based, business-impact driven

## Important disclaimer
Northstar Software Labs is fictional. All people, systems, risks, evidence, dates and findings are simulated for portfolio/learning purposes. This project does **not** claim that an actual company is ISO 27001 certified.
