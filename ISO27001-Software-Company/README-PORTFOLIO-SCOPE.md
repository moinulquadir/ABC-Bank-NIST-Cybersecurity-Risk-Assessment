# ISO 27001 Software Company — End-to-End ISMS Portfolio

## Company Scenario
**Northstar Software Labs** is a fictional 180-person B2B SaaS company headquartered in New York with a remote workforce. Its workflow platform is hosted in AWS and processes customer business information and limited personal information.

This portfolio demonstrates an ISO/IEC 27001:2022-style ISMS from initiation through operation, audit, improvement, management review, certification readiness, and closure. It is **not a certification claim** and contains no real customer data or secrets.

## ISMS Scope
The ISMS covers the people, processes, information, applications, AWS infrastructure, endpoints, corporate IT, customer support, secure SDLC, security operations, critical suppliers, New York office, and approved remote-work environment used to design, develop, operate, support, and administer the SaaS service.

Customer-owned endpoints/networks and supplier internal operations remain outside the direct ISMS boundary, while interfaces and supplier risks are managed through contractual, risk, and assurance processes.

## Lifecycle
**Initiation → Context & Scope → Assets → Risk Assessment → Risk Treatment → Statement of Applicability → Control Implementation → Policies & Procedures → Evidence → Internal Audit → CAPA → Management Review → Certification Readiness → Closure**

## Working ISMS Flows
**Access:** Request → Approval → Provisioning → MFA → Quarterly Review → Evidence

**Vulnerability:** Scan → Finding → Risk Rating → Ticket → Remediation → Rescan → Closure

**Incident:** Alert → Triage → Severity → Containment → Investigation → Recovery → Lessons Learned → CAPA

**Change:** Request → Risk → Approval → Testing → Implementation → Validation → Closure

**Supplier:** Classification → Due Diligence → Contract Requirements → Approval → Periodic Review

**Audit:** Plan → Test → Finding → CAPA → Effectiveness Check → Closure

**Management Review:** Inputs → Decisions → Actions → Follow-up

## Portfolio Disclaimer
All company names, people, systems, records, dates, findings, and evidence are fictional/simulated. This repository demonstrates practical cybersecurity governance and GRC skills; it does not represent an actual ISO certification audit or certified ISMS.
